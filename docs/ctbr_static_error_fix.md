# CTBR 内环静差修复（带臂 / 偏置负载时 arm joint 角度静态误差）

> 文件：`scripts/s500_uam_acados_state_tracking_mpc.py`，CTBR 混控（mixing）段
> 现象：s500_uam grasp 轨迹跟踪，**direct 模式**（直接下发规划的旋翼力/力矩）误差极小，
> 但切到 **CTBR 模式** 时，连机械臂关节角度都出现**稳态静差**。

---

## 1. 现象

| 模式 | base 跟踪 | arm joint 角度 |
|------|-----------|----------------|
| direct（规划旋翼力/力矩直接下发） | 很好 | 很好 |
| CTBR（总推力 + 角速度内环） | 姿态缓慢漂移 | **存在静差** |

关键疑点：arm joint 是位置直通控制（关节力矩由 MPC/规划给出），为什么换了 **base 的内环方式**
（CTBR）会把**关节角度**也带偏？答案是 **base 与 arm 的动力学耦合**——只要 base 姿态稳态有偏，
通过耦合就会反映到关节上。所以根因在 CTBR 内环本身。

---

## 2. CTBR 内环在做什么

CTBR 把 MPC 输出拆成两层：

1. **外层**：从 MPC/规划取「总推力 `T_cmd`」+「前瞻角速度设定点 `ω_sp`」。
2. **内层**（高频跑）：角速度 PID 得到「期望角加速度」

   ```
   w_cmd = Kp·e + Ki·∫e + Kd·ė ,   e = ω_sp − ω_meas
   ```

   再把 `w_cmd` 和 `T_cmd` **混控（mixing）** 回 4 个旋翼力 `r = [T1,T2,T3,T4]`。

混控就是要解：给定期望总推力和期望角加速度，每个旋翼出多少力。

---

## 3. 根因：混控漏掉了仿射偏置 α₀

### 3.1 角加速度对旋翼力是**仿射**，不是线性

base 的角加速度 `α = ω̇` 关于旋翼力向量 `r` 的真实关系是**仿射**：

```
α(r) = α₀ + B · r
```

- `B = ∂α/∂r`：控制有效性矩阵（旋翼力 → 角加速度）。
- `α₀ = α(r = 0)`：**所有旋翼力为零时的开环角加速度**。它包含
  - 重力对质心偏置产生的力矩，
  - **机械臂对 base 的反作用力矩**（arm 运动/持物 → base），
  - 其它建模力矩项。

> 这里 `B` 用对真实 plant 动力学 `f_fun` 做**有限差分**得到（而非解析分配矩阵 `A_alloc`），
> 以保证与 plant 完全一致——历史上解析 `A_alloc` 的 roll/pitch 力矩符号与 plant 相反，
> 会导致内环正反馈发散。`α₀` 则由 `α₀ = ẋ(r=u_apply) − B·u_apply` 反解得到（仿射关系精确）。

### 3.2 旧实现的 bug

旧混控直接解：

```
B · r = w_cmd          ❌（漏掉 α₀）
```

正确的应该是：让**实际**角加速度等于期望 `w_cmd`，即 `α₀ + B·r = w_cmd`，所以

```
B · r = w_cmd − α₀      ✅
```

旧式漏了 `α₀`，相当于命令旋翼**只产生 `w_cmd` 这部分角加速度，却没去抵消 `α₀`**。

### 3.3 为什么纯四旋翼一直没暴露

- 纯四旋翼**水平悬停**：质心在几何中心、无臂、无偏置负载 ⇒ `α₀ ≈ 0`。
  于是 `w_cmd − α₀ ≈ w_cmd`，旧式恰好近似正确，bug 被掩盖。
- **带臂 / 偏置负载 / 抓取物体**：`α₀ ≠ 0`（臂的反作用力矩 + 偏心重力矩）。

### 3.4 静差是怎么产生的

稳态时角速度 PID 收敛：`e → 0`、`∫e` 饱和到常值 ⇒ `w_cmd → 0`（或常值）。

- 旧式：`B·r = 0` ⇒ 旋翼力**不去平衡** `α₀` 这块臂反作用力矩/偏心力矩
  ⇒ 实际 `α = α₀ + B·r = α₀ ≠ 0` ⇒ **base 姿态持续被推着漂移**
  ⇒ 经 base–arm 耦合，反映为 **arm joint 角度静差**（以及 base 姿态偏置）。
- PID 只能靠误差「事后」去追，但 `α₀` 是个持续的偏置力矩，纯靠积分既慢又留残差。

direct 模式没有这个问题，因为它直接下发 MPC 算好的旋翼力——MPC 的模型里本来就含 `α₀`，
力是「连同 α₀ 一起算好的」。

---

## 4. 修复

在混控里显式构造 `α₀`，并把它从期望角加速度里**减掉**：

```python
# 角加速度对旋翼力为仿射：α(r)=α0+B·r
# α0=ω̇(r=0)=xdot0 − B·u_apply 为零旋翼力时的开环角加速度，
# 含重力力矩与机械臂反作用力矩。要让实际角加速度=w_cmd，须解 B·r = w_cmd − α0。
alpha0 = (
    xdot0[nq + 3 : nq + 6]
    - B @ np.asarray(u_apply[:n_rotors], dtype=float)
)
A_mix = np.vstack([np.ones((1, n_rotors)), B])   # 第1行=总推力约束 Σr=T
b_mix = np.concatenate([[T_cmd_c], w_cmd - alpha0])  # ← 关键：w_cmd − α0
rotors = np.linalg.solve(A_mix, b_mix)            # 失败则 lstsq
```

混控方程组（4 个旋翼，4 个方程）：

```
[ 1  1  1  1 ] [r1]   [ T_cmd      ]      ← 总推力
[    B (3×4) ] [r2] = [ w_cmd − α0 ]      ← 角加速度（已扣除 α0）
               [r3]
               [r4]
```

`xdot0 = f_fun(x, u_apply)`、`B[:,j]` 由 `f_fun` 对每个旋翼力 +1 的有限差分得到，
`u_apply` 是当前下发量（含 MPC 旋翼力）。

### 物理直觉

修复后等价于：**以 MPC 算出的旋翼力为前馈基线，PID 只做小量修正**。
`α₀` 携带的臂反作用力矩/偏心力矩被旋翼力主动平衡掉，稳态 `w_cmd=0` 时
`B·r = −α₀` ⇒ 实际 `α = 0`，base 姿态不再漂移，arm joint 静差随之消除。

---

## 5. 验证要点

- s500_uam grasp 轨迹：CTBR 模式下 base 姿态稳态不再漂移，arm joint 角度静差消失，
  跟踪精度接近 direct 模式。
- 纯四旋翼水平悬停：`α₀ ≈ 0`，修复前后结果一致（无回归）。
- 偏置负载 / 抓取物体场景：CTBR 现在能正确平衡偏心力矩。

---

## 6. 一句话总结

> CTBR 混控把「角加速度 ↔ 旋翼力」当成**纯线性** `B·r = w_cmd` 来解，漏掉了仿射偏置
> `α₀`（零旋翼力时的开环角加速度，含臂反作用力矩与偏心重力矩）。
> 纯四旋翼悬停 `α₀≈0` 看不出，带臂时 `α₀≠0` 导致稳态旋翼不平衡臂反作用力矩、base 姿态漂移、
> 经耦合引起 arm joint 静差。修复：解 `B·r = w_cmd − α₀`。
